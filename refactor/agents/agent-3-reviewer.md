# Agent 3 - Reviewer

## Mission

Verify that each refactor improves structure, preserves behavior, and is ready to hand back to Agent 1.

## Responsibilities

- Review only the current task
- Use `refactor/review-checklist.md`
- Flag regressions, unclear file ownership, dead code, or duplicate helpers
- Require a verification result before approving

## Output

- Review notes in `refactor/task-board.md`
- `approved` or `changes_requested`
